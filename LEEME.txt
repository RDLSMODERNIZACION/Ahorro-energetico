AP - FORZAR ÚLTIMO PERÍODO DESDE FACTURAS GENERALES V8
======================================================

Por qué V7 no alcanzó
---------------------
El frontend llama siempre al backend remoto:

https://ahorro-energetico.onrender.com

Por eso, aunque el código local del backend esté actualizado, si Render todavía
está sirviendo una versión anterior o cacheada, el endpoint puede devolver como
período inicial 2025-10.

La base YA fue verificada:
- último período general: 2026-08
- último período AP vinculado: 2026-08
- 71 AP con factura en 2026-08

Qué hace V8
-----------
No le pregunta al backend cuál es el período inicial.

Toma directamente el período más nuevo del array `invoices` que ya tiene cargado
el frontend general y luego consulta AP con ese período explícito:

...?billing_period=2026-08

Después podés cambiar manualmente el selector a períodos anteriores.

Aplicar
-------
Desde la raíz:

.\APLICAR_AP_FORZAR_ULTIMO_PERIODO_V8.ps1

Luego:

cd front
npm run dev

No modifica Supabase.
No modifica GitHub directamente.
