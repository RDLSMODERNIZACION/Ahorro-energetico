AP - ORDENAR CONSUMO E IMPORTE V10
====================================

Agrega ordenamiento en la tabla de Alumbrado Público.

Encabezados clickeables:
- CONSUMO
- IMPORTE

Comportamiento:
- primer click: mayor a menor
- segundo click: menor a mayor

También muestra una flecha:
↓ mayor a menor
↑ menor a mayor

No toca backend.
No toca Supabase.
No modifica GitHub directamente.

Aplicar desde la raíz:

.\APLICAR_AP_ORDENAR_CONSUMO_IMPORTE_V10.ps1
.\APLICAR_AP_ORDENAR_CSS_V10.ps1

Luego:
cd front
npm run dev
