AP - ÚLTIMO PERÍODO DISPONIBLE V7
=================================

Verificación realizada en Supabase:
- Último período general disponible: 2026-08
- Último período de medidores AP vinculados: 2026-08
- Facturas AP vinculadas en 2026-08: 71

Por lo tanto, que la pantalla abra en 2025-10 es un problema de selección/estado
del frontend, no de falta de datos en la base.

Este parche hace que:
1. Al entrar a Alumbrado Público la primera consulta se haga SIN período forzado.
2. Se tome data.periods[0] como el último período real.
3. El módulo quede automáticamente parado en ese período.
4. Después el usuario puede seleccionar manualmente cualquier período anterior.

No modifica backend.
No modifica Supabase.
No modifica GitHub directamente.

Aplicar desde la raíz:

.\APLICAR_AP_ULTIMO_PERIODO_V7.ps1

Después:
cd front
npm run dev
