FIX INVOICETREND V6

La V6 reemplazó accidentalmente el bloque donde estaba definida la función InvoiceTrend.
Por eso React muestra:

ReferenceError: InvoiceTrend is not defined

Este fix únicamente vuelve a insertar la función InvoiceTrend original usada por:
- Consumo
- Importe
- Demanda
- Factor de potencia

No modifica el gráfico de Ahorro tarifario.

Ejecutar desde la raíz:
.\APLICAR_FIX_INVOICETREND_V6.ps1

Después:
cd front
npm run dev
