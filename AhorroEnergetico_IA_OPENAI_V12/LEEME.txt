CONECTAR OPENAI V12

Este paquete conecta el modulo IA de la sidebar con la API real de OpenAI.

ARQUITECTURA
Front -> /api/ai/query -> Backend FastAPI -> Supabase -> OpenAI Responses API -> respuesta al front

SEGURIDAD
La OPENAI_API_KEY queda SOLO en el backend.
NO debe guardarse en Vite, React, page.tsx ni VITE_OPENAI_API_KEY.

APLICAR
Desde:
C:\Users\victo\OneDrive\Escritorio\Ahorro-energetico

Set-ExecutionPolicy -Scope Process Bypass
.\AhorroEnergetico_IA_OPENAI_V12\APLICAR_IA_OPENAI_V12.ps1

CONFIGURACION LOCAL
En la terminal donde levantas el backend:

$env:OPENAI_API_KEY="TU_CLAVE"
$env:OPENAI_MODEL="gpt-5.4"
cd back
uvicorn app.main:app --reload

En otra terminal:
cd front
npm run dev

CONFIGURACION RENDER
En el servicio backend:
Environment
OPENAI_API_KEY = tu clave
OPENAI_MODEL = gpt-5.4

Después redeploy.

IMPORTANTE
No pegues tu clave en el chat.
