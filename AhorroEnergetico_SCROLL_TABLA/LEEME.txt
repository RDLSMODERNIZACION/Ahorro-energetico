FIX SCROLL TABLA FACTURAS - AHORRO ENERGETICO

1. Descomprime este ZIP.
2. Copia la carpeta descomprimida dentro del proyecto o dejala donde quieras.
3. Abre PowerShell en la carpeta:
   Ahorro-energetico\front

4. Ejecuta:

   Set-ExecutionPolicy -Scope Process Bypass
   .\RUTA_AL_FIX\APLICAR_SCROLL_TABLA.ps1

Ejemplo, si descomprimiste el fix dentro de front:

   .\AhorroEnergetico_SCROLL_TABLA\APLICAR_SCROLL_TABLA.ps1

El script detecta la carpeta front, hace backup y aplica:
- scroll horizontal
- encabezado fijo
- columna Medidor fija
- columna Servicio fija
- barra horizontal visible

Después:
   npm run dev
