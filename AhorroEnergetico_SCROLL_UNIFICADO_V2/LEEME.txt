AHORRO ENERGETICO - FIX V2 SCROLL UNIFICADO

OBJETIVO
Unir en un solo scroll:
- facturas cargadas
- facturas pendientes del periodo

APLICACION

1. Descomprimir ZIP.
2. Abrir PowerShell en:
   Ahorro-energetico\front

3. Ejecutar:

   Set-ExecutionPolicy -Scope Process Bypass
   .\AhorroEnergetico_SCROLL_UNIFICADO_V2\APLICAR_SCROLL_UNIFICADO_V2.ps1

4. Luego probar:

   npm run dev

El script hace backup automatico antes de modificar page.tsx y layout.tsx.
