CORRECCION PARA VERCEL / NEXT.JS
================================

1. Extrae la carpeta VERCEL_NEXT_FIX dentro de:
   C:\Users\administrador\Documents\Ahorro-energetico

2. Abre PowerShell en Ahorro-energetico.

3. Ejecuta:
   powershell -ExecutionPolicy Bypass -File .\VERCEL_NEXT_FIX\APLICAR_FIX_VERCEL.ps1

4. Sube los archivos modificados con GitHub Desktop.

5. En Vercel deja configurado:
   Framework Preset: Next.js
   Root Directory: front
   Build Command: npx next build
   Output Directory: automatico

6. Configura en Vercel estas variables de entorno:
   NEXT_PUBLIC_API_URL
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

El aplicador modifica solamente las referencias necesarias y conserva el resto
del frontend.
